## 方法与 seed

**与任务书的偏离（先声明）。** 任务书要求「27 个法院各抽 2–3 份判决读引证区」。我改为
**按结构检索**：用针对引证排版特征的查询串（见下）在多个数据集上取命中片段，再把候选串
喂给本地七形状判定。理由：随机读 2–3 份判决对"发现罕见结构"的效率极低，而结构检索直接
命中排版差异。代价是**覆盖不均**，已在末尾「覆盖缺口」如实登记。

**检索串（本文件的 seed —— 重放本审计只需重跑这四条）**
1. `"Cases Cited" OR "Authorities Cited" OR "cited the following"` — dataset=CHRT,CITT,TCC,FC,BCCA,NSCA
2. `"C.L.A.D. No." OR "C.H.R.D. No." OR "L.A.C. (4th)" OR "C.L.L.C." OR "D.L.Q." OR "A.Q. no"` — 全库
3. `"CanLII" AND "at para"` — dataset=CHRT,CITT,CIRB,TATC,SCT,OHSTC,CT,FPSLREB
4. `"Appeal No. AP-" OR "File No." OR "Docket: T-" OR "D/1" OR "C.H.R.R."` — dataset=CITT,SCT,CHRT,TATC,CART,OIC,NSSM
5. `"at para" AND ("v." OR "Re")` — dataset=SST,RAD,RPD,TATC,CT,SCT,OHSTC,PSDPT,OIC,CART,CMAC,YKCA,NSSM,CITT

实际覆盖数据集：FC、FCA、BCCA、ONCA、SCC、CHRT、CIRB、FPSLREB、YKCA、CMAC（10/29）。

**形状判定方法。** 候选串喂给 `pipeline/shapes.py` 的七形状（临时脚本在系统临时目录，
未落项目内），逐条记录哪个形状命中、捕获组取到什么。**"抓不到"与"抓错了"由机器判定，
不靠肉眼。**

**频次口径。** 频次不是远程估的，是在**本地快照**（2026-08-30，SCC+ONCA）上全量正则扫描
实测，`pyarrow.iter_batches` + 列投影，只读。occurrence 计为非重叠匹配数，doc 计为至少
命中一次的判决数。扫描脚本未落项目内（一次性审计工具）；若要纳入常规观测，应按 §13.1
的规矩收进 `corpus_counts.py`。

**重要结论前置：本轮远程调查发现的四个结构问题，有三个在 SCC+ONCA 本地语料里已经
大规模存在**，不是"扩语料时才需要的预案"。27 法院调查的真实价值是**透镜**，不是预测。

## 发现

### R1【非前瞻，立即相关】`[年份] 缩写 No. 编号` 家族：不是漏抽，是 token 被污染

**原文（逐字，前后各 ~40 字符）**
```
 [1991] 2 S.C.R. 714; W.(B.) v. Mellor, [1989] B.C.J. No. 1393 (QL Systems); Lyth v. Dagg (1988), 46 C
```
```
6 C.C.L.T. (3d) 52, 91 C.P.C. (6th) 94, [2010] O.J. No. 3423 (QL), 2010 CarswellOnt 5877, affirming
```

**定位** SCC row 257（`citation_en=[1992] 2 SCR 226`）字符 19631–19653；
SCC row 650（`2012 SCC 19`）字符 10994–11014。

**七形状的实际行为（机器判定）** —— `shape_bracket` **命中了**，但捕获组是：
```
[1989] B.C.J. No. 1393  ->  year='1989'  token='B.C.J. No.'  page='1393'
[2010] O.J. No. 3423    ->  year='2010'  token='O.J. No.'    page='3423'
[1952] C.T.S. No. 14    ->  year='1952'  token='C.T.S. No.'  page='14'
```
缺的结构成分不是形状，是 **`_ABBR` 没有边界把编号词 `No.` 挡在缩写之外**：`_ABBR` 的
段间分隔集 `[ .&]+` 后接 `[A-Z][A-Za-z]*`，而 `No` 正好是大写开头，于是被吸进 token。

**为什么这比漏抽更糟** 行被抽出来了，看起来正常，但 `token` 是 `O.J. No.` 而不是 `O.J.`。
分类层拿这个 token 去查 `reporter_jurisdiction.csv` 永远查不到（表里不会有 `O.J. No.`
这个条目），整个家族会系统性落 `UNSUPPORTED`，而且**没有任何信号提示这是可修的**——它
不会出现在漏抽清单里，也不会出现在误报清单里。这正是规格 §0 说的"看起来填得很满"的
机制。

**频次（本地快照实测，2026-09-06）** 宽口径 `[年份] 大写词序列 No. 数字`：
**16,124 次 / 6,935 份判决**（SCC 5,079 次 / 1,842 份；ONCA 11,045 次 / 5,093 份）。
其中严格 Quicklaw 形式 `[年份] X.J. No. n`（O.J./B.C.J./N.S.J./Y.J./S.C.J. 等）
**10,782 次**。这是本轮所有发现里最大的一个。

**修法建议（一句话）** 在 `_ABBR` 的段循环里排除编号词 `No.`（结构性词尾边界，不是缩写
清单），或在 `shape_bracket` 的 token 与 page 之间开一个可选的 `No.` 插槽单独吸收。

### R2【非前瞻，立即相关】`YYYY CanLII nnnn` 与 `YYYY CarswellOnt nnnn`：混合大小写打穿中立引用形状

**原文**
```
im forfait GMBH v. Lexus maritime inc., 1998 CanLII 13001; Amchem Products Inc. v. British Columb
```
```
 N.S.R. (2d) 161; Visram v. Chandarana, 2007 CanLII 28334; Tolofson v. Jensen, [1994] 3 S.C.R. 10
```

**定位** SCC row 650（`2012 SCC 19`）字符 9967–9984；SCC row 663（`2012 SCC 18`）字符 8220–8237。

**七形状的实际行为** `shape_neutral_bare` **不命中**——它要求 `(?P<token>[A-Z]{2,6})`
全大写，而 `CanLII` / `CarswellOnt` / `CarswellQue` 是混合大小写。这些串落到
`shape_vol_abbr_page`：
```
1998 CanLII 13001  ->  vol='1998'  abbr='CanLII'  page='13001'   （无 year 组）
```
缺的结构成分：**年份被当成卷号**。按 PROBLEMS #10，无年份组件的形状无法参与同形异义
消歧与年份判定，所以这批引证在裁定层是"瞎"的。

**频次** **1,763 次 / 858 份判决**（SCC 777 次 / 175 份；ONCA 986 次 / 683 份）。
另有 `CarswellOnt` / `CarswellQue` 同构（未单独计数，样本中已出现两例）。

**修法建议** `shape_neutral_bare` 的 token 从 `[A-Z]{2,6}` 放宽为"大写开头的无空格
纯字母段，长度 2–12"，仍是结构约束、代码合法性仍归 `neutral_court_codes.csv`（约束二）。

### R3【非前瞻，立即相关】`C.H.R.R. D/nnnn`：字母-斜杠页码，七形状零命中

**原文**
```
Ontario Human Rights Commission (1985), 6 C.H.R.R. D/2948. Appeal dismissed, L'Heureux‑Dubé and M
```
```
 C.R.R. (2d) 295, 55 M.P.L.R. (4th) 69, 66 C.H.R.R. D/1, [2009] N.S.J. No. 13 (QL), 2009 Carswe
```

**定位** SCC row 383（`[1992] 2 SCR 321`）字符 21064–21081；SCC row 2879 附近同构。

**七形状的实际行为** **零命中**（机器判定，非推断）。同一段里 `55 M.P.L.R. (4th) 69`
被正常抽到，唯独 `66 C.H.R.R. D/1` 整条丢失。缺的结构成分：`_PAGE` 是 `(?P<page>\d+)`，
不接受 `D/2948` 这种**字母前缀 + 斜杠 + 数字**的页码。加拿大人权报告（C.H.R.R.）全系列
用这个页码体例。

**频次** **390 次 / 63 份判决**（SCC 378 次 / 59 份；ONCA 12 次 / 4 份）。
量不大但**是纯漏抽**（不是脏行），且集中在人权法领域——对"地标案例查表"这个产品用途，
人权案是高价值类别。

**修法建议** `_PAGE` 增加一个可选的字母-斜杠前缀槽（`(?:[A-Z]/)?`），与 `page_suffix`
同样显式捕获而不是静默截断。

### R4【前瞻 + 少量本地】中立引用代码超过 6 位：`[A-Z]{2,6}` 的上界是拍的

**原文**
```
l, 2016 QCTAT 6870, [2016] AZ‑51348664, 2016 LNQCTAT 1697 (Lexis), 2016 CarswellQue 14696 (WL). A
```
```
ssau) Ltd. (Dominion Investments Ltd.), 2008 QCBDRVM 4; GreCon Dimter inc. v. J.R. Normand inc
```

**定位** SCC row 2827（`2024 SCC 13`）字符 41499–41516；SCC row 2879（`2024 SCC 8`）
字符 11360–11376（`1995 ONICDRG 144`）。

**七形状的实际行为** 5 位的 `2016 QCTAT 6870` 被 `shape_neutral_bare` 正常命中；
7 位的 `2016 LNQCTAT 1697`、`2008 QCBDRVM 4`、`1995 ONICDRG 144` **不命中 neutral_bare**，
只落 `vol_abbr_page`（同 R2，丢年份语义）。缺的结构成分：上界 6 排除了真实存在的 7 位代码。

**前瞻证据（远程）** A2AJ 中 **FPSLREB**（联邦公共部门劳资关系与就业委员会，7 位）与其
法语代码 **CRTESPF**（7 位）是数据集正式名称，`2024 FPSLREB 58` 一类引证在扩语料后必然
大量出现；本地实测该形式已有 `2024 FPSLREB` 之外的同类。

**频次** 本地 7 位及以上代码 **72 次 / 27 份判决**（SCC 57 / 16；ONCA 15 / 11）——**本地量很小**。
对照：现行 2–6 位口径命中 144,609 次。所以这条**本轮不值得单独动正则**，但若 R2 按建议
把 token 放宽到 2–12 位，这条**顺带就解决了**。

**修法建议** 不单独修；并入 R2 的 token 长度放宽。

### R5【非前瞻】连字符页码 / 页码区间：静默截断，与已修复的 `12n` 同族

**原文**
```
 10 Q.B.D. 295. [22] [1902] P. 62. [23] 15 App. Cas. 210-219. [24] 14 App. Cas. 665-668. [25] 24 Can
```
```
. L.R. 446. [2] 35 Can. S.C.R. 550. [3] 17 O.R. 61-5. [4] 17 Ont. App. R. 421. [5] Sub nom.
```

**定位** SCC row 551（`[1923] SCR 107`）字符 41392–41412；SCC row 672（`(1911) 45 SCR 170`）
字符 39335–39347。

**七形状的实际行为**
```
15 App. Cas. 210-219  ->  shape_vol_abbr_page  page='210'   （'-219' 静默丢弃）
17 O.R. 61-5          ->  shape_vol_abbr_page  page='61'    （'-5' 静默丢弃）
```
`_PAGE` 的 `(?![A-Za-z0-9])` 对连字符不设防（`-` 既非字母也非数字），所以匹配成功但只吃
了区间起点。**这与 v2 已修的 `[1892] 1 Ch. 12n` 是同一个缺陷族**：产出一条看起来正常的
截断行。区别在于起点页通常仍是正确的键，所以危害小于 `12n`；但它**没有留痕**。

另一个真实子类是法语 Dalloz 引证被彻底吃错：`D. 1889-1-91` → `vol='2' abbr='D.' page='1889'`。

**频次** 本地 `卷 缩写 数字-数字` 形式 **140 次 / 103 份判决**；其中 `C.L.L.C. nnn-nnn`
（劳动法判例，页码本身就是 `210-022` 这种复合编号）**32 次 / 17 份**，全在 ONCA。

**修法建议** 比照 `page_suffix`，给 `_PAGE` 加一个显式捕获的 `page_range_end` 组，
把"取起点"变成有记录的决定而不是回溯副作用。

## 头部块与脚注块独立精读（任务 c）

远程读取 `2022 ONCA 451`、`2013 SCC 34` 头部 2,200 字符，两点观察：

1. **头部元数据块的自引用是双写的**：SCC 头部同时印 `Neutral citation\n2013 SCC 34` 与
   `Report\n[2013] 2 SCR 458`（**无句点的 `SCR`**），正文里则是 `[2013] 2 S.C.R. 458`
   （有句点）。PROBLEMS #13 的自引标记若只比对 `citation_en`，会漏掉 `Report` 那一行的
   平行汇编自引。**这是对 #13 的补充观测，不是新缺口。**
2. ONCA 头部把下级审引证印在一句话里：`reasons reported at 2021 ONSC 5961, 2022 C.L.L.C.
   210-007` —— 同时含 R5（连字符页码）与一条正常中立引用，是 R5 在头部块的实例。

## 覆盖缺口（如实登记）

1. **只覆盖 10/29 个数据集**：FC、FCA、BCCA、ONCA、SCC、CHRT、CIRB、FPSLREB、YKCA、CMAC。
   **未覆盖 19 个**：BCSC、CART、CITT、CT、NSCA、NSFC、NSPC、NSSC、NSSM、OHSTC、OIC、
   PSDPT、RAD、RLLR、RPD、SCT、SST、TATC、TCC。其中 CITT（贸易，用 `AP-2019-002` 式
   案号）、RAD/RPD（难民，用 `MB8-12345` 式档案号）、SCT（特定索赔）最可能藏有本轮
   未见的结构，建议下一轮优先。
2. **频次口径未收进 `corpus_counts.py`**：本文件五条频次由一次性审计脚本测得，脚本不在
   项目内，因此**按约束九当前不可从仓库重放**。若这些数字要进规格，必须先把模式收进
   `corpus_counts.py` 并配 `PATTERN_ASSERTIONS`。
3. **R1 的宽口径可能高估**：`F1_quicklaw_No` 的正则允许任意大写词序列 + `No.`，可能吃进
   非引证的句子。严格子集 `[年] X.J. No. n` 的 10,782 次是可靠下界，16,124 是上界。
4. **未做人工复核**：所有归类是我一人判定，未经第二人核验，整份文件按项目规矩视为
   **【待核实】**。
