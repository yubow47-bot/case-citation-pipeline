# 四方向资料收集与审批计划

日期：2026-10-02（America/Toronto）。用户要求：Luna 或 Terra 快速收集、6.1 判断，所有代理使用 medium。

## 本轮交付

1. 全部 50 个缺证缩写的逐项外部证据或明确缺口。
2. Nfld. & P.E.I.R. 的国家、省级汇编覆盖与逐案来源分别判断。
3. Que. K.B. / Sask. L.R. 的混合证据与枢密院传播风险判断。
4. 今天已修的 S.J. 同形分流独立核验。
5. gpt-6.1-sol / medium 独立审核、逐项机器可读审批记录、可读报告，以及获准证据记录的精确变更。

## 证据与审批标准

- 原始采集：gpt-6-luna / medium 三路。最终独立判断：gpt-6.1-sol / medium。
- 实际打开权威页面才算查阅；搜索摘要、受阻页面和二手复制不能作为已核实的原始证据。
- 目录名称支持汇编身份；出版地点本身不证明覆盖地域。要证明法域需来源明确映射或原始收录范围。
- 元数据、汇编收录范围、具体案件来源、审理法院四者分开。
- 同形多读按表行和结构分别审查；不得用归一化掩盖不同含义。
- 只批准来源确实支持的层级，缺口明确留待核实。
- 本轮批准属于用户授权的代理审核，不能标成 human-reviewed。审阅结果保留模型、等级、依据和限制。
- 新资料不能自行成为 case_origin / exclusive_scope_rule，也不能授权启发式身份归并和多跳法域继承。
- 不覆盖 corpus、旧 run、既有审计结果或他人未提交改动；表格变更只触及本轮获准记录。

## 基线与验证

- reporter_jurisdiction_before.csv 为本轮开始时表格快照，保留其他任务已经完成的 S.J. 修复与证据升级。
- no_evidence_targets.csv 来自六渠道 summary.csv 的 50 个目标；权重是原表登记语料行数，非本轮重新抽取计数。
- 核对表格变更的字段范围、行数和唯一性；必要时重放分类以检验是否改变语义。
- 如仅改来源、核验标签和注释，必须确认分类消费字段没有变化；不得据此宣称新全流程已验证。

## 报告与图表计划
